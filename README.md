# auris

AAC-LC без привязки к ОС: декодер и кодер MPEG-2/4 AAC Low Complexity, упаковка LATM (так AAC идёт по Bluetooth
A2DP) и ADTS. AAC — второй по распространённости кодек наушников после SBC; его поддерживают почти все наушники и
все телефоны.

## Что умеет
- **Декодер:** одиночные и парные каналы, все переключения окон (длинные, начальные, восемь коротких, конечные),
  окна sine и KBD, TNS, импульсы, замещение шумом (PNS), стерео M/S и интенсивное, частоты от 8 до 96 кГц, моно и
  стерео. Повреждённые блоки дают ошибку, а не панику.
- **Кодер:** переключение на короткие окна по детектору всплесков с заглядыванием на кадр вперёд, психоакустическая
  модель (энергия, тональность, маскирование соседних полос, порог слышимости), M/S по каждой полосе, подбор
  масштабных множителей с общим сдвигом под битрейт и резервуаром битов, точный подсчёт битов Хаффмана и разбиение
  на секции динамическим программированием, срез полосы по битрейту.
- **Упаковка:** элементы LATM с настройкой внутри потока или снаружи, кадры ADTS.

Без `std`, только `alloc` и `libm`.

## Проверено
- Декодер совпадает с декодером FFmpeg до одного младшего бита на потоках FFmpeg при частотах 8–96 кГц, моно и стерео,
  с короткими окнами, TNS, M/S, интенсивным стерео и полосами шума — в том числе на громком белом шуме, который
  FFmpeg почти целиком передаёт замещением шумом (PNS); эталонные потоки лежат в `tests/data`.
- Поток кодера FFmpeg раскодирует без ошибок, а его раскодированный звук совпадает с нашим декодером до одного бита
  (`cargo test -- --ignored`, нужен `ffmpeg`). Битрейт держится в пределах нескольких процентов от заданного.

Чего пока нет в кодере: PNS, TNS и интенсивного стерео — на битрейтах A2DP (256–320 кбит/с) они не нужны.

```sh
cargo run --release --example aac -- encode 44100 2 256000 < in.raw > out.aac
cargo run --release --example aac -- decode < out.aac > out.raw
```
